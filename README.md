# hugoCommunication.github.io

Petits sites perso hébergés sur GitHub Pages.

| Dossier      | Adresse                                              | Contenu                                   |
|--------------|------------------------------------------------------|-------------------------------------------|
| `/`          | https://hugocommunication.github.io/                 | Page d'accueil : choix du service         |
| `date/`      | https://hugocommunication.github.io/date/            | Billet pour deux (proposer un date)       |
| `portions/`  | https://hugocommunication.github.io/portions/        | Placard à portions (calories, codes Yazio) |

Chaque service est autonome dans son dossier : ses images et ses fichiers restent à l'intérieur.
Pour ajouter un service, créer un nouveau dossier avec son `index.html` et ajouter une carte dans `index.html` à la racine.

`.nojekyll` désactive le traitement Jekyll de GitHub Pages : les fichiers sont servis tels quels.
